Colorimeter CSV import

{% set lab_ref = config.measurement.colorimeter_csv.lab_reference %}

Illuminant / observer: ICC profiles need L*a*b* measured as D50 / 2°. Many handheld colorimeters (3nh PS110, CHNSpec DS-173, ...) default to D65 / 10°. Readings in the wrong setting shift every color in the profile, and "verify" can't notice, because it checks the profile against those same readings. Set the device to D50 / 2° before measuring (D65 / 2° also works; this tool converts it). A 10° observer can't be converted: re-measure.
